# Rohan Verma — Portfolio

🔗 **Live site:** [portfolio-rohan-verma.vercel.app](https://portfolio-rohan-verma.vercel.app)

Personal portfolio of a data engineering / analytics grad (MS Data Analytics Engineering, Northeastern University).

## Built with

- **React** + **Vite**
- **Tailwind CSS**
- **Framer Motion** (animations)
- **Lucide React** (icons)
- **Vercel** (hosting)

## Highlights

- Animated hero where the portrait's eyes follow your cursor
- Light / dark theme
- Collapsible sidebar navigation
- Fully responsive

> The source code lives in a private repository. This repo exists to showcase the live site.
